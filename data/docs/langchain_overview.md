# LangChain 概览

LangChain 是一个用于构建大语言模型（LLM）应用的开发框架，核心目标是把「模型能力」组合成「可落地的应用」。

## 六大核心抽象

1. **Models（模型）**：统一封装各类 LLM 与聊天模型，屏蔽不同厂商的接口差异。
2. **Prompts（提示词）**：用模板管理输入，支持变量替换与 few-shot 示例。
3. **Chains（链）**：把多个组件按顺序串联，例如「检索 -> 拼接 Prompt -> 调用模型」。
4. **Agents（智能体）**：让模型自主决定调用哪些工具、按什么顺序调用，应对开放性问题。
5. **Memory（记忆）**：在多次对话之间保存上下文，使 Agent 具备多轮对话能力。
6. **Retrievers（检索器）**：从外部知识库（向量库）中召回与问题相关的片段，是 RAG 的基础。

## 为什么需要这些抽象

直接调用一次 API 很简单，但真实应用往往需要：组合多个步骤、接入私有知识、调用外部工具、记住历史。LangChain 提供的抽象正是为了解决这些工程化问题，让开发者专注于业务逻辑。

> 关键词：Models、Prompts、Chains、Agents、Memory、Retrievers。
