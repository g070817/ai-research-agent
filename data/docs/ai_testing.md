# 如何测试 AI / LLM 应用

LLM 应用的不确定性（非确定性输出）让传统软件测试方法论不够用，需要一套针对性的测试策略。

## 三类测试层次

1. **单元测试（Unit）**：针对确定性组件，例如工具函数、解析器、检索器。用 Mock/ Fake 模型隔离 LLM，保证快速、稳定、零成本。
2. **集成测试（Integration）**：用真实 API 验证端到端链路，但应标记并控制频率，避免高昂调用成本。
3. **评估（Eval）**：用 golden dataset（黄金数据集）衡量模型输出质量，指标包括准确率、召回率、相关性、无害性等。

## 黄金数据集（Golden Dataset）

Golden dataset 是一组「问题-标准答案/标准证据」的配对。评估时让系统回答这些问题，再比对输出是否包含预期证据，或用 LLM-as-Judge 打分。

要点：

- 数据要覆盖主干流程、边界情况与异常输入。
- 检索类任务重点看 **recall（召回率）**：问题对应的证据段落是否能被检索出来。
- 把评估脚本化，做到「改一行代码，跑一遍评估」的回归能力。

## Fake 模型在测试中的价值

LangChain 提供 Fake/Generic 聊天模型，可预置固定输出与工具调用，使 Agent 主循环测试完全脱离真实 API：确定性、可重复、毫秒级、零费用。这是 AI 测试工程师必须掌握的核心手段。

> 关键词：单元测试、集成测试、评估、Golden Dataset、召回率、Fake 模型、LLM-as-Judge。
